# avmugurkilic.com

Avukat Mustafa Uğur KILIÇ — büro web sitesi.

Statik site. Netlify bu depoya bağlıdır; `main` dalına yazılan her değişiklik kendiliğinden yayına alınır.

## Dosyalar
- `index.html` — ana sayfa
- `makaleler.html` — makaleler
- `guncel.html` — hukuki gelişmeler (aylık güncellenir)
- `vekaletname.html` — vekâletname rehberi
- `en.html` — İngilizce sayfa
- `*.woff2` — yazı tipleri (sitede barındırılır)
